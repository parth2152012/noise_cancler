01 / The approach

Trust measurements
only when physics agrees.

01

Sense

A compact rolling pre-filter conditions each gyroscope sample at a 400 Hz control-loop rate.

02

Differentiate

Discrete first and second derivatives expose angular changes that cannot be explained by frame inertia.

03

Weigh

A Gaussian trust factor smoothly lowers confidence as jerk moves beyond a calibrated physical threshold.

04

Predict

During a spike, a localized kinematic estimate carries the state forward—then safely times out.

01.5 / Embedded-ready

One engine.
No runtime.

The production path is a fixed-memory Rust library for bare-metal flight controllers. It uses #![no_std], needs no heap allocation, and exposes both a compact output API and the live trust value for telemetry.

Read the integration guide →
#![no_std]

let mut filter = DerivativeFilterEngine::new(
    6_500.0, 0.0025
);

let result = filter.update_with_trust(gyro_x);
// result.value  → corrected signal
// result.trust  → measurement confidence

Why it matters

Filtering without
flying blind.

Conventional moving averages trade noise reduction for delay. In a responsive flight-control loop, that delay can become an over-correction.

Noise Cancler scores the measurement itself, then blends it with a short-horizon prediction. The intended result: vibration resilience with near-zero added phase lag.

A simulation prototype, not yet flight-certified hardware.
